# Academic Autopilot — versión 1.4.0

## Novedades
- El Chat recupera los mensajes pendientes al volver la conexión o regresar a la app.
- Repaso permite usar los apuntes guardados de un cuaderno en Chat y Studio, y explica cómo configurar la IA cuando falta.
- La app queda preparada para ofrecer distintos estilos más adelante, sin cambiar su aspecto actual.

## Correcciones
- Se corrige un conflicto de guardado de Office al cambiar de documento o importar; el horario permite desplazarse y editar los últimos días en móvil.
- El aviso de actualizar ya no ofrece versiones iguales o anteriores a la instalada.
- Configuración se simplifica: se retiran las tarjetas de Canva, NotebookLM y Word/Excel.

## Avisos
- El instalador de Windows no está firmado y Windows puede mostrar un aviso de seguridad.
- El instalador para Mac todavía no se ha probado.
