# Atlantium — versión 1.5.0

## Novedades
- La app ahora se llama Atlantium, también en el escritorio, conservando tus datos y tu sesión.
- Puedes marcar tareas como entregadas aunque las hayas enviado por otro medio, y consultarlas en Entregas.
- Las tareas vencidas permiten aplazar el recordatorio sin cambiar el plazo del colegio.
- Las notas se organizan por Trimestre y Unidad, con filtros y medias de cada grupo; la media global se conserva.

## Correcciones
- El escritorio muestra una opción de reintento cuando no puede conectar, evitando recargas continuas.
- Se mejora la instalación de la web como app y la lectura sin conexión de los PDF ya guardados.

## Avisos
- El instalador de Windows no está firmado y Windows puede mostrar un aviso de seguridad.
- El instalador para Mac todavía no se ha probado.
